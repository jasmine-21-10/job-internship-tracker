# Job & Internship Tracker

A simple web-based application to track job and internship applications in one place.

## 🚀 Features

- Add and manage job/internship applications
- Track application status
- Store company and job details
- Simple and user-friendly interface
- Data stored using JSON
- Web interface using HTML, CSS and JavaScript
- Python backend

## 🛠️ Technologies Used

- Python
- HTML
- CSS
- JavaScript
- JSON

▶️ How to Run

2. Open the Project Folder
cd job-internship-tracker
3. Make Sure Python is Installed

Check Python using:

python --version
4. Run the Application
python main.py
5. Open the Application

After running main.py, open the URL shown in the terminal in your web browser.

📌 Purpose

The purpose of this project is to provide a simple and organized platform for students and job seekers to manage their job and internship applications.

It helps users keep track of important application details such as company name, job/internship role, application status, and other relevant information in one place.
